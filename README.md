# embedded-journey

Eight months of bare-metal STM32. Sep 2026 – Jun 2027.

I scored 4/90 on a closed-book embedded diagnostic on 5 September 2026.
This repository is the record of what I did about it.

**Platform:** STM32F446RE (NUCLEO-F446RE), register level, no HAL.

## Structure
- `logs/` — weekly engineering log: predictions, measurements, what broke
- `host-c/` — Months 1-2, C on the host
- `stm32/` — Months 3-8, firmware
- `notes/` — manual drills, debug reports, design notes
